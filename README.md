🛒 Budget Sniper - Casual Editionブラウザで動作する、予算管理に特化したお買い物シミュレーター。値札（税抜価格）を入力するだけで、残り予算内で「税抜あと何円分の商品が買えるか」を瞬時に逆算します。🛠 Features税抜残高のリアルタイム逆算: 予算（税込）から現在の合計を差し引き、あと税抜いくら分の商品がカゴに入れられるかを表示します。スマホ最適化: 外出先での利用を想定した、片手で操作しやすいUI/UX。カジュアルデザイン: 買い物のストレスを軽減する、目に優しいパステル調の配色。予算の動的変更: 1,000円以外の予算にも柔軟に対応。リスト管理: 入力ミスをした際も、個別に商品を削除可能。🚀 Usageindex.html をブラウザで開きます。上部の「予算設定」に今日の買い物の予算を入力します（デフォルトは1,000円）。商品の値札に書かれている「税抜価格」を入力し、「リストに追加」をタップします。「あと税抜 〇〇円分」という表示を確認しながら、予算ギリギリを狙ってください。📐 Logic消費税率は 10% 固定です。予算オーバーを防ぐため、残高の逆算には以下の式を用いています。$$\text{残りの税抜可能額} = \left\lfloor \frac{\text{予算} - \text{現在の税込合計}}{1.1} \right\rfloor$$※ 1円の誤差も許容しないよう、端数は Math.floor（切り捨て）で処理しています。💻 Technical StackHTML5CSS3 (Flexbox, CSS Variables)JavaScript (ES6+)
